THE ROUTING LOOP

Jev judges.
Your Agent acts.

01 / OBSERVECollect state

Task, real candidates, permissions, risk, and current evidence.

02 / DECIDEAsk Jev

Choice, Score, or Noul returns typed answers and probabilities.

03 / POLICYApply the gate

Allow, confirm, review, or stop without expanding authority.

04 / EXECUTEKeep control

Your Agent host executes and records the append-only receipt.

WHAT JEVROUTER ADDS

Make the next choice explicit.

01 / MODEL

Model routing

Compare only approved models by quality, context, latency, cost, and tool-use needs. Escalate when no candidate is safe enough.

02 / TOOL

Tool routing

Put a typed decision in front of Skills, MCP tools, and CLIs. Preserve permissions, risk, confirmation, and execution ownership.

03 / SUBAGENT

Subagent routing

Choose the specialist for the current state, then hand execution back to your Agent host with a receipt you can inspect.
